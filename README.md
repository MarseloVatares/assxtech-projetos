# Portfólio de projetos ASSXTECH

Quatro projetos demonstrativos:
1. Fluxo de atendimento via WhatsApp — HTML, CSS e JavaScript.
2. Página comercial — HTML, CSS e JavaScript.
3. Controle de estoque — PHP e MySQL.
4. Gestão financeira — PHP e MySQL.

## Execução local
Use XAMPP, importe `assxtech_projetos/banco-de-dados/assxtech_projetos.sql` no phpMyAdmin e ajuste as credenciais nos arquivos `config.php`.

## Observações
- Os projetos PHP precisam de hospedagem com PHP e MySQL.
- O fluxo de WhatsApp é uma simulação e não envia mensagens reais.
- O número na página comercial é fictício e deve ser substituído antes do uso.
- Não publique credenciais reais de banco de dados.
